# Quiz Game 🎯

A simple command-line quiz game written in Python.  
The program asks the player multiple-choice questions, validates input, and calculates the final score.

---

## Features

- Multiple-choice quiz system
- Input validation
- Score calculation
- Beginner-friendly Python project
- Easy to expand with more questions

---

## Technologies Used

- Python 3

---

## Project Structure

```bash
quiz-game/
│
├── main.py
└── README.md
```

---

## How It Works

1. The program displays a question.
2. The user selects an answer from 1–4.
3. Input is validated to prevent invalid entries.
4. After all questions are answered, the final score is displayed.

---

## Example

```bash
What is the largest planet in our solar system?

1) Earth
2) Mars
3) Jupiter
4) Saturn

Your answer (1-4): 3
```

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/quiz-game.git
```

Go into the project folder:

```bash
cd quiz-game
```

Run the program:

```bash
python main.py
```
